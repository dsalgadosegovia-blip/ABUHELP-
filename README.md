# ABUHELP

Launcher y teléfono accesible para Android, con contactos grandes, asistente por botón y recordatorios locales.

## Estado

Proyecto en desarrollo. Todavía no hay APK validada. Los contactos, PIN y recordatorios son datos locales configurados por el cuidador y no se incluyen en este repositorio.

La interfaz propia de llamadas requiere seleccionar ABUHELP como aplicación de teléfono predeterminada. El control de llamadas personales de WhatsApp no está implementado ni garantizado.

Las compilaciones de prueba se publicarán como artefactos de GitHub Actions, claramente identificadas como versiones de evaluación. Requieren pruebas en el dispositivo antes de uso cotidiano.
